# Security Policy

Security Statement: The intended users of this repository are only the owner (Jason Letourneau) and the owner of the original repository (Prof. Matthew Lamoureux). However, anyone is free to view this data and
run these programs on their machines. If this data fell into malicious hands, the main security risk would be questions of academic integrity (none of the code or data in this repository is particularly sensitive
or private). Still, precautions have been taken. A ruleset for pull requests has been added, preventing attackers from merging any files to the repo and from deleting any files from the repo. With this, the repository
should be safe.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

To report a vulnerability, email the repository owner (jason.letourneau@uconn.edu) immediately for a fix.
